# 西澳北线行程 · Coral Coast

**2026.9.26 早到珀斯 → 10.6 00:16 离开** · **单人自驾 · 珀斯 ↔ 卡尔巴里折返**

考虑到只有一人开车、且不希望异地还车，行程最北止于 **卡尔巴里**。
往返约 **1,150 km**，每天单段车程多在 1.5–2.5 小时，车在珀斯取还。

## 为什么不去 Exmouth

单人往返 Exmouth 约 2,500 km，多出 4 个纯赶路日，且末日要接红眼航班。
若仍想去宁格鲁，建议 **珀斯往返飞 Exmouth（Learmonth）**、当地租小车，不必长途独驾。
