# 西澳行程 · Coral Coast

**2026.9.26 早到珀斯 → 10.6 00:16 离开** · 单人自驾 · 珀斯取还车

页面提供 **四个方案**，点标签即可切换（地图、日程、车程表同步变化）。

## 四方案对照

| 方案 | 总里程 | 最长单日 | 适合 |
|------|--------|----------|------|
| 卡尔巴里折返（原版） | 约 1,150 km | 约 2.5h | 最省力，彻底放松 |
| 卡尔巴里 + 西南 | 约 1,750 km | 约 4.5h | 南北都看，还想撸微笑袋鼠 |
| Exmouth 自驾往返 | 约 2,500 km | 约 7h | 必须浮潜且不介意长途 |
| 北线单程 + Exmouth 飞回 | 约 1,250 km + 机票 | 约 4.5h | 想看完整北线又不走回头路 |

### 1. 卡尔巴里折返（原版）

尖石阵 → Geraldton ×2 → Kalbarri ×3 → Dongara → Cervantes → 珀斯。
9/29 为完全弹性日（Abrolhos 观光飞行 / 海边 / 整天不开车）。

### 2. 卡尔巴里 + 西南线

9/27 整天在弗里曼特尔与**罗特尼斯岛看微笑袋鼠**（quokka），9/28 再取车北上。
北线压到 Kalbarri 2 晚，10/2 回珀斯后南下 Busselton、玛格丽特河 2 晚。

### 3. Exmouth 自驾往返

Geraldton → Kalbarri → Carnarvon → Exmouth ×3 → Coral Bay → Cervantes。
10/4 需连开约 7 小时，单人驾驶请谨慎。

### 4. 北线单程自驾 + Exmouth 飞回

一路向北开完整北线：尖石阵 → Geraldton → Kalbarri ×2 → Carnarvon → Coral Bay → Exmouth ×2，
10/5 在 Learmonth 机场还车飞回珀斯，不走回头路。

注意：需确认**异地还车**（珀斯取 / Exmouth 还）的附加费，并订上午或中午的航班。
