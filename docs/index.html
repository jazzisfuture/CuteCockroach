Notes

订房、驾驶与季节

订房优先顺序

  • Exmouth（尽量 3–4 晚）
  • Kalbarri（2 晚）
  • 过渡夜：Carnarvon；订不到可试 Coral Bay，或 Kalbarri 早发直开 Exmouth
  • Geraldton / Dongara、珀斯首尾相对好订
  • 回程机票：Exmouth → 珀斯尽早定，车在 Exmouth 还

实用提醒

  • 夏天峡谷务必早出，中午避暑，带足水
  • 北上加油站间距大，过半箱就考虑加油
  • Turquoise Bay 注意水流方向；Oyster Stacks 看潮汐窗口
  • 鲸鲨船约 3–7 月需提前订
  • 主点基本柏油路，普通轿车可完成
