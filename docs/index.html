Notes

往返自驾要点

节奏怎么拆

  • 北上：珀斯 → Geraldton → Kalbarri(2) → Carnarvon → Exmouth
  • 宁格鲁：优先保证 2 整日（浮潜 + Cape Range）
  • 南返：Exmouth → Carnarvon/Geraldton → 珀斯，至少 2 天
  • 切忌 Exmouth 一天开回珀斯（12–14h，危险且无乐趣）
  • 鲨鱼湾继续跳过；Coral Bay 可作北上或南返备选过夜

实用提醒

  • 往返油费、轮胎、疲劳都要算进去；轮流开车最好
  • 过半箱就加油；偏远段加油站可能早关
  • 夏天中午少开长途、多休息；峡谷早出
  • 回程可在尖石阵补拍（若北上赶日落）
  • 车在珀斯取还，保险/里程条款出发前确认
